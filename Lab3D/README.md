# Лаборатория 3D — Интерактивные научные опыты для детей (8–13 лет)

3D-игра и познавательная лаборатория для Android-телефонов и планшетов (Kotlin + Jetpack Compose + OpenGL ES 2.0). Работает полностью офлайн, без рекламы.

## 6 интерактивных 3D-опытов
1. **🌋 3D Вулкан и Химия** — добавляй соду, уксус, мыло и красители (или потряси телефон!), наблюдай рост давления CO₂, изменение pH и 3D-извержение пены.
2. **⚡ Электрическая цепь и Закон Ома** — замыкай 3D-рубильник, меняй напряжение и сопротивление, следи за бегущими 3D-электронами (`I = U / R`), подключай **лампочку** (может перегореть с искрами!), **мотор с пропеллером** и **электромагнит**, поднимающий железные гайки.
3. **🌈 Призма Ньютона и Лазер** — вращай стеклянную, водяную или алмазную 3D-призму, раскладывай белый свет на 7 лучей радуги или управляй длиной волны моно-лазера (`400–700 нм`).
4. **🧲 Магнитное поле и Левитация** — заставь 3D-магнит парить в воздухе на магнитной подушке (отталкивание `N ⟷ N`), меняй силу магнита (Феррит / Алнико / Неодим N52) и смотри, как 36 3D-стрелок компасов выстраиваются вдоль линий магнитного поля.
5. **🚀 Запуск 3D Ракеты** — настраивай тягу двигателя и запас топлива, выбирай планету (**Земля, Луна, Марс, Юпитер**) и выведи ракету выше линии Кармана (`100 км`) в космос!
6. **🪐 Гравитация и Орбиты** — запускай 3D-планеты и кометы вокруг Солнца, меняй скорость запуска и массу звезды, наблюдай эллиптические орбиты, падение на Солнце или космический побег!

## Игровые и обучающие механики
- **Вращение 3D-сцены на 360°** пальцем + **зум щипком** + двойной тап для сброса камеры.
- **18 научных заданий (миссий)** с автоматической проверкой, XP и званиями (от *Юного стажёра* до *Нобелевского лауреата*).
- **«🔬 Теория»** с формулой и простым объяснением + **«🧠 Викторина»** (18 вопросов) для каждого опыта.
- **Адаптивный интерфейс** для телефонов и планшетов + встроенный синтезатор звуковых эффектов.

## Как собрать APK на GitHub
1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория **содержимое** папки `Lab3D` (чтобы `settings.gradle.kts` и папка `.github` находились в корне).
3. Перейдите во вкладку **Actions** → workflow **Build Lab3D APK** запустится автоматически (или нажмите **Run workflow**).
4. После завершения откройте запуск → **Artifacts** → скачайте **Lab3D-apk**.

Минимальная версия Android: 7.0 (API 24).
