# 🔬 Юный учёный 3D — лаборатория опытов для детей 8–13 лет

Android-игра с интерактивными **3D-опытами**. Ребёнок проводит эксперимент прямо на телефоне или планшете: вращает сцену пальцем, сыплет соду, бросает предметы в воду, крутит призму. После опыта можно открыть объяснение «💡 Почему?» и пройти тест. За каждый опыт — до 3 звёзд.

Игра работает **полностью офлайн**, без рекламы и без доступа в интернет (в приложении нет разрешения INTERNET).

## Опыты

| | Опыт | Предмет | Что делает ребёнок |
|---|---|---|---|
| 🌋 | Вулкан из соды | Химия | Насыпает соду ложкой, выбирает краску, наливает уксус — извержение пены. Без соды реакции нет. |
| 🛟 | Тонет — не тонет | Физика | Бросает 7 предметов в аквариум (плотность от 0,08 до 7,8). Солит воду — и яйцо всплывает. |
| 🌈 | Радуга из призмы | Оптика | Крутит призму и фонарик; луч честно рассчитывается по закону преломления. Белый свет даёт радугу, красный лазер — нет. |
| 🪐 | Гравитация на планетах | Астрономия | Бросает молоток и перо на Земле, Луне, Марсе и Юпитере. Считает время падения, свой вес и высоту прыжка. |
| 💡 | Электрическая цепь | Электричество | Замыкает выключатель, проверяет 6 материалов: проводник или изолятор. Видно, как бегут электроны. |
| 🌞 | День, ночь и времена года | География | Двигает Землю по орбите, выбирает город (Москва, Мурманск, Сочи, экватор, Сидней). Видно полярную ночь и что будет без наклона оси. |

Каждый опыт содержит: интерактивную 3D-сцену, объяснение простым языком, интересный факт, безопасный опыт «Попробуй дома» и тест из 3 вопросов.

## Как собрать APK

### Вариант 1 — GitHub Actions (без установки чего-либо)
1. Создайте репозиторий на GitHub и загрузите туда **всё содержимое** этой папки (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions** — сборка «Build APK» запустится сама (или нажмите *Run workflow*).
3. Через 3–5 минут откройте завершённый запуск → внизу раздел **Artifacts** → скачайте `YoungScientist3D-debug-apk` (zip с файлом `app-debug.apk`).
4. Скопируйте APK на телефон и установите (разрешите «Установка из неизвестных источников»).

### Вариант 2 — Android Studio
1. *File → Open* → выберите эту папку.
2. Дождитесь синхронизации Gradle.
3. *Build → Build App Bundle(s) / APK(s) → Build APK(s)*.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3 — командная строка
```bash
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
```
Нужны JDK 17 и Android SDK (переменная `ANDROID_HOME` или файл `local.properties` с `sdk.dir=...`).

## Требования
- Android 8.0 (API 26) и новее, телефоны и планшеты, любая ориентация экрана.
- Обновлённый Android System WebView / Chrome (для поддержки WebGL и ES-модулей).

## Как устроен проект

```
app/src/main/
├── java/ru/younglab/lab3d/MainActivity.java   ← оболочка: полноэкранный WebView, кнопка «Назад»
├── assets/www/                                ← сама игра (HTML + JavaScript + Three.js)
│   ├── index.html, css/style.css
│   └── js/
│       ├── main.js         ← меню, звёзды, окна «Почему?» и тесты, общий 3D-движок
│       ├── sound.js        ← звуки, синтезируемые на лету (без аудиофайлов)
│       ├── menuScene.js    ← 3D-фон главного меню
│       ├── common.js       ← стол, свет, вспомогательные функции
│       ├── exp/*.js        ← по файлу на каждый опыт
│       └── lib/            ← Three.js r170 (MIT)
└── res/                                       ← иконка, тема, название
```

**Как добавить свой опыт:** скопируйте любой файл из `js/exp/`, поменяйте `id`, тексты, вопросы и сцену в `start(ctx)`, затем добавьте импорт в список `EXPERIMENTS` в `main.js`.

**Проверить игру без телефона:** в папке `app/src/main/assets/www` запустите `python3 -m http.server` и откройте `http://localhost:8000` в Chrome.

## Публикация в Google Play
Для Play нужен файл `.aab`, подписанный вашим ключом: *Build → Generate Signed App Bundle / APK* в Android Studio. Поменяйте `applicationId` в `app/build.gradle.kts` на свой.
