# OPUTI — 3D Научные опыты для Android

Репозиторий с двумя 3D-приложениями научных опытов и автоматической сборкой APK через GitHub Actions:

| Папка | Приложение | Артефакт в Actions |
|---|---|---|
| `Lab3D/` | **Лаборатория 3D** | `Lab3D-apk` |
| `YoungScientist3D/` | **YoungScientist3D** | `YoungScientist3D-apk` |

## Где скачать APK
Откройте вкладку **Actions** → последний запуск **Build All 3D Lab APKs** → раздел **Artifacts** внизу страницы.
